키 없이 넣기 — 클로드 채팅에서 받아 붙여넣기

클로드 채팅에는 구글 지도 커넥터가 붙어 있습니다. 거기서 한 번 물어보고 결과를 여기에 붙여넣으면 키 없이도 평점이 들어갑니다. 사진은 이 방법으로 가져올 수 없어요.

API 키로 받는 법
  1. Google Cloud 콘솔에서 프로젝트를 만들고 결제를 연결합니다. 이 앱이 쓰는 만큼은 무료 한도 안입니다.
  2. “Places API (New)”를 사용 설정합니다.
  3. 사용자 인증 정보에서 API 키를 만듭니다.
  4. 키 제한에서 웹사이트를 고르고 이 페이지 주소를 넣으세요. 정적 페이지라 키가 브라우저에 노출되니 이 제한은 꼭 걸어야 합니다.
  5. API 제한에서 Places API (New)만 허용합니다.

공식 사이트·예매처에서 확인한 입장료만 더했어요. 밥값과 교통비는 빠져 있습니다.

알아둘 것

  • 11월 23일 월요일이 일본 공휴일(근로감사의 날)이라 토·일·월이 연휴입니다. 토요일 네즈와 은행나무길, 일요일 긴자는 평소보다 붐빕니다.
  • 츠키지 장외시장은 일요일에 대부분 닫습니다. 이번 일정에선 토요일 아침이 유일한 기회예요.
  • 현금이 필요한 곳: 츠키지 시장.
  • Bookshelf Fuzkue는 대화 금지에 규칙이 길어요. 가기 전에 홈페이지 안내를 한 번 읽어두세요.
  • 일요일은 18시 나리타 비행기에 맞춰 긴자를 13:25쯤 떠나야 합니다. 그래서 13시에 여는 모리오카 서점을 맨 뒤로, 10:30에 여는 긴자 츠타야를 앞으로 옮겼어요.
  • 토요일이 가장 깁니다. 지치면 선택 표시가 붙은 곳부터 빼세요. 날짜 화면의 “선택 일정 접기”로 한 번에 숨길 수 있어요.
