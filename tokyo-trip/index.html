새 버전이 준비됐어요.

2026.11.18 – 11.22

늦가을 도쿄

11월 18일 수요일부터 22일 일요일까지. 아카사카에서 출발하는 서점, 미술관, LP바의 닷새.

예약할 것

체크하면 일정의 예약 배지가 “예약 완료”로 바뀝니다. 이 기기에 저장돼요.

알아둘 것

  • 11월 23일 월요일이 일본 공휴일(근로감사의 날)이라 토·일·월이 연휴입니다. 토요일 네즈, 일요일 아티존은 평소보다 붐빕니다.
  • 츠키지 장외시장은 일요일에 대부분 닫습니다. 이번 일정에선 토요일 아침이 유일한 기회예요.
  • 현금이 필요한 곳: 츠키지 시장, Little Soul Cafe.
  • Bookshelf Fuzkue는 대화 금지에 규칙이 길어요. 가기 전에 홈페이지 안내를 한 번 읽어두세요.
  • 모리오카 서점은 13시에 엽니다. 일요일 비행기가 이르면 토요일 저녁으로 옮기세요.
  • 토요일이 가장 깁니다. 지치면 선택 표시가 붙은 곳부터 빼세요. 날짜 화면의 “선택 일정 접기”로 한 번에 숨길 수 있어요.

가기 전에

도쿄에서 데이터가 없어도 열리게 해두는 준비입니다.

홈 화면에 추가

앱처럼 열리고, 비행기 모드에서도 일정이 뜹니다.

아이폰은 사파리에서 공유 버튼을 누르고 “홈 화면에 추가”, 안드로이드는 크롬 메뉴에서 “앱 설치”를 고르세요.

구글 장소 정보 가져오기

평점, 리뷰 수, 분류, 그날의 영업시간, 사진을 한 번에 받아 카드에 넣습니다. 받아두면 오프라인에서도 보여요.

키 만드는 법
  1. Google Cloud 콘솔에서 프로젝트를 만들고 결제를 연결합니다. 이 앱이 쓰는 만큼은 무료 한도 안입니다.
  2. “Places API (New)”를 사용 설정합니다.
  3. 사용자 인증 정보에서 API 키를 만듭니다.
  4. 키 제한에서 웹사이트를 고르고 이 페이지 주소를 넣으세요. 정적 페이지라 키가 브라우저에 노출되니 이 제한은 꼭 걸어야 합니다.
  5. API 제한에서 Places API (New)만 허용합니다.
