# 늦가을 도쿄 — 11월 18일부터 22일까지

2026년 11월 도쿄 닷새 일정을 길 위에서 한 손으로 보는 모바일 웹앱. 빌드 없이 파일 그대로 굴러갑니다.

## Tokyo Lines — 여행을 노선도로

닷새를 도쿄 지하철 노선 넷으로 봅니다. 처음 노선은 **Claude 추천**(스카이트리·도쿄 타워·츠키지·스타벅스 리저브 로스터리·네즈미술관·국립신미술관을 꼭 넣고, 겹치는 컨셉은 하나씩만)이고, 도구 > 노선 템플릿에서 다른 플랜으로 바꿀 수 있어요. 목 G(긴자선 주황), 금 T(도자이선 하늘), 토 H(히비야선 은색), 일 M(마루노우치선 빨강). 장소는 역 번호(G01, G02…)가 붙은 블록이고, 숙소가 있는 아카사카미쓰케가 환승역입니다.

1. 휴대폰 브라우저로 열고 **홈 화면에 추가**하면 앱처럼, 비행기 모드에서도 열립니다.
2. **노선도** — 숙소에서 뻗는 네 노선과 날짜별 안내. 여행 중엔 맨 위에 열차 안내판처럼 "지금/다음 역"이 뜨고 길찾기가 바로 됩니다.
3. **운행표** — 그날 노선을 세로 한 줄로 봅니다. 역(장소)을 **길게 눌러 끌면** 순서가 바뀌고, 위의 다른 날짜에 놓으면 그날로, 끄는 동안 아래에 나타나는 **빼기** 칸에 놓으면 보관함으로 빠집니다. 맨 아래 **장소 추가**를 누르면 이 동네·찜·숙소 근처·종류별 목록이 올라와요(넓은 화면에선 오른쪽에 붙어 있고 거기서 끌어 넣을 수 있어요). 숙소 출발 시각은 숫자를 눌러 바꿔요. 도착 시각은 이동 거리·여는 시각·예약 시각으로 다시 계산되고(추정), 휴무·마감·예약 시각과 부딪히면 빨갛게 표시돼요. 역을 누르면 머무는 시간, 시각 고정, 찜, 메모·찍을 자리·설계자가 나옵니다. 여행 중에 열면 오늘 노선부터 보여요.
4. **지도** — 모은 곳 87곳을 지도에 핀으로. 위의 **컨셉**(미술관·건축, 서점·북카페, LP바, 먹고 마시기, 단풍·전망, 찜)이나 **지역**(목 북동쪽, 금 동쪽 도심, 토 남서쪽, 일 긴자…)을 누르면 그것만 남아요. 지역을 누르면 그날 노선과 역 번호가 같이 보여서 어디에 넣으면 좋을지 한눈에 보이고, 아래 사진 카드의 **"토에 넣기 +8분"**을 누르면 가장 덜 돌아가는 자리에 들어가요. 여행 중엔 **내 위치** 버튼으로 가까운 순. "목록"을 누르면 예전처럼 목록으로 보고 새 장소를 검색해 담습니다.
5. **도구** — **다른 기기로 옮기기**(아이폰에서 복사 → 아이패드에서 붙여넣기. 노선·찜·예약 체크·필름·구글 키가 같이 가요), 예약 체크, 필름 기록, 일본어 한마디, 숙소 주소 크게, 긴급 연락처, 노선 템플릿(지역별 기본·필름·건축·책과 레코드·느린 카페·정원), 구글 장소 정보(키를 넣으면 사진·평점·영업시간), 백업과 캘린더 파일.
6. 예산·교통·공항·날씨 안내는 **이전 화면**(`classic.html`)에 있고, 도구 맨 아래에서 열 수 있어요.

## 어떻게 생겼나

도쿄 지하철 표지판 문법입니다. 색은 노선색 넷, 기호는 노선 원·역 번호판·환승역 셋, 글꼴은 Pretendard와 Barlow Condensed 둘. 끌어서 놓기는 SortableJS(`vendor/sortable/`, MIT)를 내려받아 넣었습니다.

## 배포

### Vercel

저장소 루트의 `vercel.json`이 모든 경로를 `tokyo-trip/`으로 넘깁니다. 그래서 Vercel에 이 저장소를 연결하기만 하면 사이트 루트에서 앱이 열립니다. 따로 설정할 것은 없고, Production Branch만 `main`이면 됩니다.

### 평점·사진을 앱 안에 넣기 (선택)

**준비 > 할 일**의 &ldquo;구글 장소 정보&rdquo;에 Places API 키를 넣으면(기기마다 한 번. 지도 탭의 &ldquo;키 붙여넣기&rdquo;로도 되고, 다른 기기로 옮기기에 같이 가요), 26곳의 평점·리뷰 수·분류·가격대·그날의 영업시간·사진을 한 번에 받아 운행표와 보관함에 붙입니다. 받아두면 오프라인에서도 보입니다.

- 키는 Google Cloud 콘솔에서 만듭니다. &ldquo;Places API (New)&rdquo;를 켜고, 키 제한에서 **웹사이트**를 골라 이 페이지 주소를 넣으세요. 정적 페이지라 키가 브라우저에 노출되니 이 제한은 꼭 필요합니다.
- 이 앱이 쓰는 양(한 번에 26곳)은 무료 한도 안입니다.
- 구글 정책상 받아온 정보는 **30일까지만** 보관합니다. 30일이 지나면 표시가 멈추고 다시 받으라고 알려줍니다. 11월 여행이면 출발 직전에 한 번 받아두면 됩니다.
- 키를 넣지 않아도 앱은 지금 그대로 동작합니다. 평점·사진 줄만 안 보일 뿐이에요.
- **키가 없어도 평점은 넣을 수 있습니다.** 같은 칸의 "키 없이 넣기"를 열고 "물어볼 문장 복사"를 누르면 27곳 이름이 들어간 질문이 복사됩니다. 그걸 클로드 채팅(구글 지도 커넥터가 붙어 있는 쪽)에 붙여넣고, 돌려받은 JSON을 다시 앱에 붙여넣으면 끝입니다. 사진만 이 방법으로는 못 가져옵니다.

## GitHub Pages

1. 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, 브랜치를 `main`과 `/ (root)`로 지정합니다.
2. 몇 분 뒤 `https://<계정>.github.io/<저장소>/tokyo-trip/` 에서 열립니다.
3. 경로는 전부 상대 경로라 하위 경로에서도 서비스 워커까지 그대로 동작합니다.

파일을 고쳐 다시 올릴 때는 `sw.js` 맨 위의 `VER`을 올려 주세요. 안 올리면 예전에 캐시된 화면이 계속 보입니다. 새 버전이 준비되면 페이지 위에 "새 버전이 준비됐어요 · 새로고침" 띠가 뜹니다.

## 내려받아 보기

인터넷 없이 파일만으로 보려면 폴더째 받아서 로컬 서버로 여세요. `file://`로 열면 서비스 워커와 일부 기능이 동작하지 않습니다.

```bash
cd tokyo-trip
npx http-server . -p 8080     # 또는 python3 -m http.server 8080
```

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 페이지 전부. CSS·JS·일정 데이터가 한 파일에 들어 있습니다. |
| `sw.js` | 오프라인 캐시. 설치할 때 앱 파일을, 이후 본 지도 타일·폰트·장소 사진을 저장합니다. |
| `manifest.webmanifest` | 홈 화면 추가용 설정. |
| `vendor/` | Leaflet 1.9.4. 오프라인 때문에 CDN 대신 받아 두었습니다. |
| `icons/` | 앱 아이콘. `tools/` 없이 손으로 갈지 말고 필요하면 다시 생성하세요. |
| `data/places.csv` | Google My Maps 가져오기용 장소 목록. |
| `data/tokyo-trip.ics` | 폰 캘린더용 일정 파일. |
| `tools/make-csv.mjs` | 일정 데이터에서 CSV와 캘린더 파일을 다시 만듭니다. `node tools/make-csv.mjs` |
| `CLAUDE.md` | Claude Code용 작업 지시서. 남은 일과 규칙이 들어 있습니다. |
