# 늦가을 도쿄 — 11월 18일부터 22일까지

2026년 11월 도쿄 닷새 일정을 길 위에서 한 손으로 보는 모바일 웹앱. 빌드 없이 파일 그대로 굴러갑니다.

## 여행 중에 쓰는 법

1. 휴대폰 브라우저로 페이지를 엽니다.
2. **홈 화면에 추가** — 아이폰은 사파리 공유 버튼 → "홈 화면에 추가", 안드로이드는 크롬 메뉴 → "앱 설치". 앱처럼 열리고 비행기 모드에서도 일정이 뜹니다.
3. **출발 전 와이파이에서** **준비 > 할 일**의 "가기 전에"에서 "다섯 날짜 지도 한 번에 열기"를 한 번 눌러 두세요. 화면에 보인 지도 조각만 기기에 저장됩니다. 저장된 개수는 바로 아래에 표시됩니다.
4. 도쿄에서는 데이터 없이도 일정·시간·일본어 이름·예약 배지가 모두 보입니다. 지도 타일이 없으면 간단 지도로 자동 전환되고, 지도·길찾기 버튼은 인터넷이 있을 때만 열립니다.

화면에서 할 수 있는 것 — 아래 탭 다섯 칸

- **홈** — 출발까지 남은 날, 예약 현황(몇 개 남았는지), 닷새를 한눈에 보는 날짜 카드, 테마 바로 가기, 길에서 바로 쓰는 버튼(숙소 주소 크게·일본어·긴급). 여행 중에는 맨 위에 **지금 있어야 할 곳과 다음 곳**이 크게 뜨고 길찾기가 바로 됩니다.
- **일정** — 위쪽에서 날짜를 고르면 그날 지도와 시간표가 나옵니다. 장소 사이마다 직선거리와 확인된 노선이 적혀 있고, 먼 이동은 상자로 표시돼요. 비 올 확률이 50%를 넘는 날엔 야외 장소에 비 올 때 대안이 뜹니다. 일요일 화면에서는 비행기 시간으로 긴자를 떠날 시각을 계산해 줍니다.
- **테마** — 여행 책자처럼 건축·사진(설계자, 찍을 자리, 날짜별 골든아워·블루아워, 지나가며 볼 건물), 내가 저장한 곳(인스타에서 디깅한 곳, 분홍 태그가 저장한 계정), 미술관·박물관, 서점·북카페, LP바, 먹을 곳, 정원·단풍·전망으로 모았습니다. 줄을 누르면 그날 그 자리로 가고, 테마마다 일정 밖 추천이 있어 "일정에 넣기"로 원하는 날·시간에 끼워 넣을 수 있어요(기기에만 저장, 앞뒤 일정과 30분 안쪽이면 경고).
- **준비** — 할 일(예약·출발 전 체크, 홈 화면 추가, 지도 미리 저장, 캘린더, 구글 장소 정보), 숙소·교통, 예산·팁(확인된 입장료 합계와 알아둘 것).
- **도움** — 필름 기록(홈의 "필름 한 컷"으로 어디서 몇 번째 컷을 찍었는지 적고, 인스타 캡션용으로 복사), 일본어 한마디(누르면 크게, 🔊 누르면 일본어로 읽어줌), 긴급 연락처(누르면 전화), 날씨.
- 장소 이름을 누르면 일본어 이름이 크게 떠요. 역무원이나 택시 기사에게 보여주세요. 지도 버튼은 구글 지도의 그 장소 카드로 바로 들어갑니다.
- 여행 중 날짜는 새벽 4시에 바뀝니다. 새벽까지 여는 바에서 열어도 그날 일정이 나와요.

## 어떻게 생겼나

2026년 9월에 토스·애플 지도 느낌으로 다시 다듬었습니다. 글꼴은 Pretendard 하나(`vendor/pretendard/`, 오프라인에서도 보이게 파일로 넣었습니다), 밝은 회색 바탕에 흰 카드, 강조색은 은행잎 하나입니다. 아래는 처음 버전 이야기입니다.

저장소의 `design-md/` 컬렉션에서 세 가지를 가져와 섞었습니다. The Verge의 StoryStream 타임라인(왼쪽 레일의 모노 시각, 알약 모서리 카드, 지금 있어야 할 곳만 은행잎으로 꽉 채우는 액센트 블록), Linear의 4px 간격 체계와 헤어라인, Apple의 17px 본문과 여백. 은행나무 색과 Hahmlet 제목은 그대로입니다.

## 배포

### Vercel

저장소 루트의 `vercel.json`이 모든 경로를 `tokyo-trip/`으로 넘깁니다. 그래서 Vercel에 이 저장소를 연결하기만 하면 사이트 루트에서 앱이 열립니다. 따로 설정할 것은 없고, Production Branch만 `main`이면 됩니다.

### 평점·사진을 앱 안에 넣기 (선택)

**준비 > 할 일**의 &ldquo;구글 장소 정보 가져오기&rdquo;에 Places API 키를 넣고 버튼을 누르면, 26곳의 평점·리뷰 수·분류·가격대·그날의 영업시간·사진을 한 번에 받아 카드에 붙입니다. 받아두면 오프라인에서도 보입니다.

- 키는 Google Cloud 콘솔에서 만듭니다. &ldquo;Places API (New)&rdquo;를 켜고, 키 제한에서 **웹사이트**를 골라 이 페이지 주소를 넣으세요. 정적 페이지라 키가 브라우저에 노출되니 이 제한은 꼭 필요합니다.
- 이 앱이 쓰는 양(한 번에 26곳)은 무료 한도 안입니다.
- 구글 정책상 받아온 정보는 **30일까지만** 보관합니다. 30일이 지나면 표시가 멈추고 다시 받으라고 알려줍니다. 11월 여행이면 출발 직전에 한 번 받아두면 됩니다.
- 키를 넣지 않아도 앱은 지금 그대로 동작합니다. 평점·사진 줄만 안 보일 뿐이에요.
- **키가 없어도 평점은 넣을 수 있습니다.** 같은 칸의 "키 없이 넣기"를 열고 "물어볼 문장 복사"를 누르면 27곳 이름이 들어간 질문이 복사됩니다. 그걸 클로드 채팅(구글 지도 커넥터가 붙어 있는 쪽)에 붙여넣고, 돌려받은 JSON을 다시 앱에 붙여넣으면 끝입니다. 사진만 이 방법으로는 못 가져옵니다.

## GitHub Pages

1. 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, 브랜치를 `main`과 `/ (root)`로 지정합니다.
2. 몇 분 뒤 `https://<계정>.github.io/<저장소>/tokyo-trip/` 에서 열립니다.
3. 경로는 전부 상대 경로라 하위 경로에서도 서비스 워커까지 그대로 동작합니다.

파일을 고쳐 다시 올릴 때는 `sw.js` 맨 위의 `VER`을 올려 주세요. 안 올리면 예전에 캐시된 화면이 계속 보입니다. 새 버전이 준비되면 페이지 위에 "새 버전이 준비됐어요 · 새로고침" 띠가 뜹니다.

## 내려받아 보기

인터넷 없이 파일만으로 보려면 폴더째 받아서 로컬 서버로 여세요. `file://`로 열면 서비스 워커와 일부 기능이 동작하지 않습니다.

```bash
cd tokyo-trip
npx http-server . -p 8080     # 또는 python3 -m http.server 8080
```

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 페이지 전부. CSS·JS·일정 데이터가 한 파일에 들어 있습니다. |
| `sw.js` | 오프라인 캐시. 설치할 때 앱 파일을, 이후 본 지도 타일·폰트·장소 사진을 저장합니다. |
| `manifest.webmanifest` | 홈 화면 추가용 설정. |
| `vendor/` | Leaflet 1.9.4. 오프라인 때문에 CDN 대신 받아 두었습니다. |
| `icons/` | 앱 아이콘. `tools/` 없이 손으로 갈지 말고 필요하면 다시 생성하세요. |
| `data/places.csv` | Google My Maps 가져오기용 장소 목록. |
| `data/tokyo-trip.ics` | 폰 캘린더용 일정 파일. |
| `tools/make-csv.mjs` | 일정 데이터에서 CSV와 캘린더 파일을 다시 만듭니다. `node tools/make-csv.mjs` |
| `CLAUDE.md` | Claude Code용 작업 지시서. 남은 일과 규칙이 들어 있습니다. |
